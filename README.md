# epiclint

> [!WARNING]\
> Some rules present in [the rules file](./docs/rules.md) are not yet implemented and will come soon.

This is an unofficial linter for Epitech TypeScript projects inspired by the Epitech C Coding Style.

## How to install

You can install it with `npm`.

```bash
npm install -g epiclint
```

Now you can simply use `epiclint` with our without a path to start the program.

## How to dev

To install it, you need to use the following commands:

```bash
npm install
npm run build
npm link
```

Now you can use the command `epiclint` to start the program on your code, anywhere.
